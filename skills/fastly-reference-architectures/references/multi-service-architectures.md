# Multi-service reference architectures

## fastly-serverless-cms — Compute + KV Store + Object Storage
- **Repo:** github.com/chrisbuckley/fastly-serverless-cms
- **Source:** community (chrisbuckley)
- **Demonstrates:** a full CMS (reader-facing blog, admin editor, image uploads, RSS, sitemaps, cache management) built from Compute + KV Store + Object Storage with zero origin infrastructure.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19

## fastly-serverless-checkers — Compute + Fanout + KV Store
- **Repo:** github.com/chrisbuckley/fastly-serverless-checkers
- **Source:** community (chrisbuckley)
- **Demonstrates:** real-time multiplayer game logic running in Compute, with Fanout for push updates and KV Store for persistence — all three products, no backend servers.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19

## infiniteboard — Compute + Fanout + KV Store + Object Storage
- **Repo:** github.com/anaramirezmorones/infiniteboard
- **Source:** community (anaramirezmorones)
- **Demonstrates:** whiteboard logic running in Compute, with Fanout for real-time multi-user collaboration, KV Store for state persistence, and Object Storage for assets — four products in one application, the widest combination found in this research pass.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19

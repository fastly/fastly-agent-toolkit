# Multi-service reference architectures

## fastly-serverless-cms — Compute + KV Store + Object Store
- **Repo:** github.com/chrisbuckley/fastly-serverless-cms
- **Source:** community (chrisbuckley)
- **Demonstrates:** a full CMS (reader-facing blog, admin editor, image uploads, RSS, sitemaps, cache management) built from Compute + KV Store + Object Store with zero origin infrastructure.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19

## fastly-serverless-checkers — Compute + Fanout + KV Store
- **Repo:** github.com/chrisbuckley/fastly-serverless-checkers
- **Source:** community (chrisbuckley)
- **Demonstrates:** real-time multiplayer game state (Fanout for push, KV Store for persistence) with no backend servers.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19

## infiniteboard — Compute + Fanout + KV Store + Object Storage
- **Repo:** github.com/anaramirezmorones/infiniteboard
- **Source:** community (anaramirezmorones)
- **Demonstrates:** real-time multi-user collaboration (Fanout), state persistence (KV Store), and asset storage (Object Storage) combined in one application — the widest product combination found in this research pass.
- **Watch out for:** none known as of last verification.
- **Last verified:** 2026-08-19
